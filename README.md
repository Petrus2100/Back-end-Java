# Back-end-Java

back-end básico feito com java para cadastro de dados.

## Assunto

Nesse projeto está disponivel o front e o back do projeto do site de aluguel de veículos, requisitos necessários para o rodar, é ter uma IDE de Java instalado, ter o mysql-connector-Java-8.0.20. esse conector é muito importante, para a conexão do back ao banco de dados.

## Atenção

Esse projeto pode passar por atualizações tanto para melhoria no código quanto para completar o projeto.
